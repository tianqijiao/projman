## 1. 编写原则

- 测试优先覆盖业务闭环、跨年度执行、附件证据链、导出和数据清理。
- 测试数据只使用 `tmp_path`、内存 SQLite 或临时 SQLite，不读取真实 `data/app.db`。
- 上传附件使用最小 PDF 字节 `b"%PDF-1.7 fake"`；非法附件同时覆盖“扩展名错误”和“文件头错误”。
- 页面级行为使用 FastAPI `TestClient` 和 HTML 响应断言，不引入 Playwright。
- 当前不保留已知 `xfail`；若后续测试暴露需求与实现不一致，才使用严格 `xfail` 记录规格缺口，并写明退出条件。
- 审核意见中指出过的问题必须转成明确测试契约，避免只停留在文档说明。

## 3. 当前严格 xfail 清单

当前无 `xfail`。此前记录的非法年度筛选、项目级附件类型边界、非法 PDF Web 层错误和附件越界读取缺口均已修复，并转为正式通过测试。

## 4. 批次执行清单

### 第一批：核心业务闭环

- 登录成功后新增项目。
- 编辑合同金额和合同期。
- 上传采购依据、合同审签、盖章合同、其他附件。
- 维护年度验收日期、付款日期。
- 上传验收单和发票。
- 在台账中筛选到已完成项目。
- 导出 Excel 并下载项目 ZIP、年度 ZIP。

### 第二批：跨年度和合同管理年

- 建档年度早于服务期首年时生成合同管理年。
- 多年服务期按可付款年度均分金额。
- 手动年度金额不被主档保存覆盖。
- 手动合同管理年清空年度金额，并跳过验收付款待办。
- 缩短合同期时清理超出年度和对应附件。

### 第三批：安全和异常边界

- 未登录访问业务页和附件接口时跳转登录。
- 非 PDF 在 service 层拒绝。
- 非 PDF 在 Web 层返回可控错误。
- 项目级新增入口拒绝年度级附件。
- 附件删除不允许越过数据目录删除外部文件。
- 附件读取不允许越过数据目录返回外部文件。
- 非法年度筛选回退为全部年度，不导致 500。

### 第四批：输入校验回归

- 新增和编辑项目时，空白项目名称被拒绝，且不写入空名称项目。
- 新增、编辑主档、编辑年度执行时，`abc` 这类非法金额返回 400。
- 新增、编辑主档、编辑年度执行时，`inf`、`-inf`、`nan`、`1e309` 这类非有限金额返回 400。
- 编辑主档和年度执行时，非法日期返回 400。
- 合同开始日期晚于结束日期时，保存被拒绝。
- 设置续采提醒天数为 0 或负数时，保存被拒绝。

### 第五批：文档与配置一致性

- `.env.example` 包含账号、密码、密钥、数据库路径、数据目录。
- 启动脚本包含 `.venv` 创建、`.env` 读取、默认账号密码和 8765 启动。
- README 保持本机地址、数据库、附件目录说明。
- 需求文档测试结果与实际 `pytest` 输出保持同步。
