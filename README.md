# 运维项目管理工具

一个面向个人或小范围内网使用的运维项目台账系统，用来管理年度预算项目、跨年度合同、验收付款状态和全过程 PDF 附件。

项目默认本地运行，数据存放在本机 `data/` 目录，适合学校信息中心这类需要长期维护项目资料、但又不想上复杂平台的场景。

## 主要功能

- 年度看板：按年度统计项目总数、已立项、未签合同、未验收、未付款和续采提醒。
- 项目台账：按年度、关键词、状态筛选项目，并显示预算合计、合同合计和待补资料数量。
- 跨年度执行：合同服务期可自动展开为多个年度执行记录，支持合同管理年。
- 附件归档：支持采购依据、合同审签 PDF、盖章合同扫描件、验收单、发票和其他 PDF 附件。
- 状态计算：合同、验收、付款状态同时依赖字段和关键附件，避免只有日期没有证据材料。
- ZIP 下载：可下载项目全部附件，也可下载某一年度相关附件。
- Excel 导出：按当前筛选条件导出台账，金额列保留数值格式。
- 本地设置：可调整续采提醒提前天数，默认 60 天。
- 输入校验：拒绝空白项目名称、非法日期、非法金额和非有限金额。

## 快速启动

在项目根目录执行：

```powershell
.\scripts\start.ps1
```

启动后访问：

- 本机：`http://127.0.0.1:8765`
- 局域网或 Tailscale：`http://<这台电脑的局域网或 Tailscale IP>:8765`

默认账号密码均为：

```text
admin / admin
```

正式使用前建议在 PowerShell 中设置环境变量：

```powershell
$env:PROJMAN_USERNAME="admin"
$env:PROJMAN_PASSWORD="你的密码"
$env:PROJMAN_SECRET_KEY="一段随机字符串"
.\scripts\start.ps1
```

也可以在本机创建 `.env` 文件，参考 `.env.example`。

## 数据目录

运行时数据保存在 `data/`：

```text
data/app.db                 SQLite 数据库
data/attachments/           项目级 PDF 附件
data/annual_attachments/    年度执行 PDF 附件
```

`data/` 中的真实业务数据不会提交到 Git。当前仓库只跟踪 `data/README.md`，用于保留目录说明。

`.env`、`.venv/`、`tmp/`、`logs/` 也不会提交。

## 从 Git 更新代码

如果另一台电脑已经使用过本工具，并且已经有自己的 `data/` 附件和数据库，请在原项目目录中更新代码：

```powershell
git pull
```

不要删除或覆盖另一台电脑上的：

```text
data/
.env
```

如果必须重新 clone，请先备份旧目录中的 `data/` 和 `.env`，再复制回新目录。

## 开发验证

运行全部测试：

```powershell
uv run pytest
```

当前测试覆盖：

- 登录和会话保护。
- 年度看板与续采提醒。
- 台账筛选、搜索、导出。
- 跨年度执行和合同管理年。
- 项目级与年度级附件上传、预览、下载、删除。
- 附件越界读取和删除保护。
- 非 PDF、非法金额、非法日期、空白项目名等异常输入。
- 项目删除和磁盘附件同步清理。

## 注意事项

- 本项目是轻量本地工具，不替代采购、合同审签、财务付款或 OA 系统。
- 当前 MVP 是单用户模式，不包含多人角色、统一身份认证和审计流。
- 上传的正式附件目前限定为 PDF。
- 正式使用前务必修改默认密码和 `PROJMAN_SECRET_KEY`。
